# AI / ML Boundary

Signal-to-Proof treats AI and machine learning as supporting capabilities inside an evidence system, not as shortcuts around causal identification.

## Appropriate roles

AI and ML can help with:

- pattern discovery across large signal spaces;
- predictive segmentation and propensity estimation;
- anomaly and data-quality detection;
- hypothesis generation;
- schema and evidence review;
- model-specification candidates;
- test prioritization;
- result explanation for technical and executive audiences;
- workflow orchestration around repeatable measurement tasks.

## What they do not earn by themselves

A predictive model can become more accurate without becoming more causal.

A language model can produce a more persuasive explanation without changing the evidence grade.

A synthetic or simulated population can help pressure-test assumptions without becoming observed behavior.

A richer feature set can reduce measured imbalance without guaranteeing that hidden selection has been removed.

## System rule

```text
Prediction -> prioritizes where to look
Correlation -> measures what moves together
Identification -> tests whether the effect can be isolated
Counterfactual -> defines what would have happened otherwise
Causal inference -> estimates what changed because of intervention
```

No AI or ML layer is permitted to promote the evidence grade on its own.

That boundary is intentional. The value of intelligent tooling is to make the search for evidence faster, more structured, and more decision-useful while preserving the distinction between a plausible pattern and a defensible effect.
